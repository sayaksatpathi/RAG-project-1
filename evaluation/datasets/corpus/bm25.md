# BM25

BM25, also called Okapi BM25, is a sparse lexical ranking function used by
search engines to estimate the relevance of documents to a query. It extends
the TF-IDF idea with term-frequency saturation controlled by a parameter k1 and
document-length normalization controlled by a parameter b. BM25 rewards query
terms that appear often in a document while penalizing very long documents so
they do not dominate purely because they contain more words. BM25 is strong for
queries that contain exact identifiers, error codes, or rare domain terms.
